Tôi muốn bắt đầu dự án mới này. Hãy:

1. Đọc `docs/project-brief.md` và `CLAUDE.md` để hiểu context.
2. Dùng brainstorming skill để làm rõ requirements.
3. Hỏi clarifying questions từng câu một.
4. Đề xuất 2-3 approaches với trade-offs.
5. Trình bày design từng phần, đợi tôi duyệt.
6. Sau khi duyệt, ghi spec và tạo implementation plan.

**Nhắc lại: không viết code trước khi design được duyệt.**
